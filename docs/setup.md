# 導入手順

所要時間は 30 分ほどです。最初は、普段の Vault ではなく、新しく作ったテスト用の Vault で試してください。

## 1. Google Cloud で OAuth クライアントを作る

このプラグインは、利用者自身の OAuth クライアントでログインします。

1. [Google Cloud コンソール](https://console.cloud.google.com/) で、新しいプロジェクトを作ります。
2. 「API とサービス」の「ライブラリ」で、**Google Drive API** を有効にします。
3. 「Google Auth Platform」で同意画面を設定します。
   - 対象は **外部** にします。
   - 「データアクセス」に追加する権限は `https://www.googleapis.com/auth/drive.file` **だけ**にします。
4. 「クライアント」で、種類が **デスクトップ アプリ** のクライアントを作ります。
5. 表示されたクライアント ID とシークレットを、パスワード管理ツールなどに控えます。Vault やリポジトリには置かないでください。
6. 「対象」で、公開ステータスを **本番環境** にします。
   - 「テスト」のままだと、ログインが 7 日で切れます。
   - 本番にするには、「ブランディング」にホームページとプライバシーポリシーの URL が必要です。自分用のページを公開してください。このリポジトリの `site/` を下書きに使えます。
   - Google の審査は申請しなくても使えます。ログインのときに「Google はこのアプリを確認していません」と出るので、自分で作ったクライアントであることを確かめてから続行します。

## 2. デスクトップに入れる

1. Obsidian の設定の「コミュニティプラグイン」で、制限モードをオフにします。
2. **BRAT**（作者 TfTHacker）をインストールして有効にします。
3. BRAT の **Add beta plugin** で `TommyPrime/gdrive-vault-sync` を追加します。
4. 「インストール済みプラグイン」で **GDrive Vault Sync** を有効にします。

BRAT を使わない場合は、[Releases](https://github.com/TommyPrime/gdrive-vault-sync/releases) から `main.js` と `manifest.json` を取得し、Vault の `.obsidian/plugins/gdrive-vault-sync/` に置きます。

## 3. ログインして最初の同期をする

1. GDrive Vault Sync の設定に、クライアント ID とシークレットを入れます。
2. **ログイン** を押し、ブラウザで許可します。
3. 不安なら **試行モード** をオンにして、コマンド **試行（計画を見るだけで、何も書き込まない）** で計画を確かめます。
4. コマンド **同期を実行** を選びます。初回は確認画面が出るので、内容を確かめて **実行** を押します。

マイドライブに `Obsidian/<Vault 名>/` ができ、ファイルが入ります。
最後にコマンド **端末と Drive を照合** を実行し、すべて 0 件なら同期できています。

Drive のフォルダは Vault の名前で決まります。他の端末でも、**同じ名前の Vault** を作ってください。

## 4. 他のデスクトップを追加する

2 台目以降も、手順 2 と 3 を同じ名前の空の Vault で行います。初回の確認画面には、Drive からのダウンロードが並びます。

## 5. モバイル（iPad、Android）を追加する

モバイルではブラウザでのログインができないので、デスクトップのログインを渡します。

1. モバイルで同じ名前の Vault を作り、手順 2 と同じく BRAT でプラグインを入れます。iPad では iCloud に保存しない Vault にしてください。
2. デスクトップの GDrive Vault Sync の設定で、「モバイル用トークン」の **表示** を押します。
3. 表示された文字列をモバイルへ移します。
   - **iPad:** カメラアプリは文字列の QR を読めません。デスクトップが Mac なら、文字列の欄で `Cmd+A` → `Cmd+C` を押し、ユニバーサルクリップボードで渡します。
   - **Android:** カメラか Google レンズで QR を読み取り、文字列をコピーします。
4. モバイルの設定の「モバイル用トークン」に貼り付けて **接続** を押します。
5. コマンド **同期を実行** で最初の同期をします。

文字列はチャットやメールで送らないでください。貼り付けた後は、クリップボードに別の文字をコピーして消しておきます。

## 困ったとき

- **ブラウザで許可したのに、ログイン済みにならない:** シークレットが空でないか確かめて、もう一度ログインします。
- **マイドライブに `Obsidian` フォルダが 2 つある:** `drive.file` の権限では、このプラグインが作ったフォルダしか見えません。手で作った同じ名前のフォルダとは別物です。紛らわしければ、設定の「Drive のフォルダ名」を変えます。
- **自動で同期されない:** プラグインを更新した後は、Obsidian を再読み込みするまで新しい版が動きません。デスクトップは `Cmd+R`（Windows は `Ctrl+R`）で再読み込みします。
- **「確認待ち」で止まった:** 削除が多いなど、確認が必要な同期です。コマンド **同期を実行** で内容を確かめます。
- **原因を調べたい:** コマンド **ログをコピー** でログを取れます。ログにトークンは含まれませんが、ファイル名は含まれます。
